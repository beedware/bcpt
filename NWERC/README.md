# NWERC problem sheets

Main-contest statements for the ICPC Northwestern Europe Regional Contest,
with one PDF per edition. Warm-ups, solutions, and judge data are not included.

Coverage: **1989 and every year from 1992 through 2025**. No regional problem
sheet was found for 1990 or 1991. The 1989 and 1995 archive copies contain
problems A–D; it is unclear whether those copies are complete. The 1994
booklet is titled *Western European Regional*. The [2026 edition](https://2026.nwerc.eu/schedule)
was not yet held when this collection was assembled.
